kind: Tests: ssd_chunk_scan and selective_scan backward NaN pins (no kernel change)
---
Test-only. `ssd_chunk_scan_backward_nan` compares `SsdChunkScanBackwardPlan` (f32, f16, bf16) with an f64 reverse-mode oracle of the Mamba-2 recurrence written in plain IEEE arithmetic, over a finite control (positive control: values match) and a NaN in dy, x, B, C, dt and A (batch 2, heads 2, 16 steps): the NaN pattern of dx, dB, dC, ddt and dA matches the oracle cell for cell (for example a NaN in A gives 521 NaN cells in both) and the finite values agree within tolerance. Each NaN probe asserts the oracle really is NaN somewhere, so the comparison cannot pass vacuously. No divergence found, so no kernel changes. `selective_scan_backward_nan` does the same for the Mamba-1 `SelectiveScanBackwardPlan` (no z gate, D skip, bias or softplus; batch 2, 4 channels, d_state 4, 16 steps; probes NaN in dy, u, B, C, delta, A; e.g. a NaN in A gives 125 NaN cells in both): the pattern matches the oracle cell for cell in f32, f16 and bf16, and the control matches on values. No divergence. Not probed: `+inf` inputs, other shapes (chunk sizes, d_state beyond 4), the optional z gate, D skip, delta bias and softplus paths.
