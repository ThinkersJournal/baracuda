kind: Tests: ssd_chunk_scan backward NaN pins (no kernel change)
---
Test-only. `ssd_chunk_scan_backward_nan` compares `SsdChunkScanBackwardPlan` (f32, f16, bf16) with an f64 reverse-mode oracle of the Mamba-2 recurrence written in plain IEEE arithmetic, over a finite control (positive control: values match) and a NaN in dy, x, B, C, dt and A (batch 2, heads 2, 16 steps): the NaN pattern of dx, dB, dC, ddt and dA matches the oracle cell for cell (for example a NaN in A gives 521 NaN cells in both) and the finite values agree within tolerance. Each NaN probe asserts the oracle really is NaN somewhere, so the comparison cannot pass vacuously. No divergence found, so no kernel changes. Not probed: `+inf` inputs, other shapes (chunk sizes, d_state beyond 4), and `selective_scan` backward.
