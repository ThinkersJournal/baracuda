kind: Added: new crate `baracuda-hip-emit` (HIP/AMD emitter, ROADMAP H1 stage 1), 0.56.12, not published
---
`Hip` implements the neutral generator's `Backend` for AMD (HIP C++). Stage 1 lowers the kernel-layer memory and control subset (`Let`, `Load`, `Assign`, `Store`, `If`, `For`, `While`, `Break`, `Continue`, `Return`, a block `Barrier` as `__syncthreads()`, static `__shared__` arrays, thread/block builtins, `__launch_bounds__`) with the same argument block (ABI B) as `baracuda-cuda-emit`. Everything NVIDIA-specific (`cp.async`, `Mbar*`, `CopyBulk`, `GridDep*`, `Wgmma*`, `Tcgen05*`, `ldmatrix`/`stmatrix`, named and cluster barriers) and everything whose AMD semantics are unchecked (warp collectives, `Cast`/`Fma`/`Bitcast`, a subgroup size) is declined by name with the reason; a HIP emitter declines the statements the IR marks as NVIDIA-patent-noted, it does not translate them. The crate keeps the Unpopped version it works with (one-version exception), is `publish = false` until the PM allocates a release, and joins the driver-free CI lists (build, clippy, test, doc, and the 1.88 MSRV set). **Not compiled with `hipcc`** (no ROCm here): tests pin the source shape, and the `nvrtc-syntax-check` feature compiles the text with NVRTC as a C++ syntax check only.
