## Findings

1. **The census misses the loader.** The whole surface sits behind `#[cfg(feature = "cuvs")]` (off by default, `lib.rs:33`, `:491`), and the `Cuvs` struct and its 18 `cuvs_*` accessors are generated by the
   `cuvs_fns!` macro. The source walk counts the `cfg`-gated code (102 rows) but cannot see macro output, and the default-feature expansion drops the `cfg`-gated `ffi` module, so the tool never sees them.
   Feature-on expansion has `pub struct Cuvs` and 18 `pub fn cuvs_*` methods (grep over the expanded file: 1 and 18). The census has 18 `PFN_*` type rows, one for each of the 18 expanded methods, which is the
   control that the two sets correspond. Corrected population: 102 + 1 + 18 = **121** rows with the `cuvs` feature on. A general consequence: any item behind a non-default feature **and** generated by a macro is
   missing from the census. Not measured how many other crates that touches.
2. **Class is wrong by the census README's own rule.** README §3 says every `*-sys` crate other than our two C-ABI crates is `vendor-mirror` (rule 7), but `classify.py` sends a `private-mod` item that a `pub use` glob
   covers to `stable` first (rule 4's escape). All 102 rows are `private-mod` (`mod ffi` at `lib.rs:34`, `pub use ffi::*` at `:492`), so 102 of 103 are `stable`. The same applies to `baracuda-tensorrt-sys` (28 `stable`), so
   130 rows in non-C-ABI `-sys` crates are `stable` where §3 says `vendor-mirror`; `baracuda-cuda-sys` and the other `-sys` crates are unaffected (public modules). The fix is to test the `-sys` rule before the re-export
   escape; not made here, it belongs in the census change, and would move those 130 rows out of the `stable` total.
3. **Closed enums mirror C enums.** `cuvsDistanceType` (`#[repr(i32)]`, 22 variants, includes `Precomputed`) and `cuvsFilterType` (`#[repr(C)]`, 3 variants) are plain Rust enums with no `#[non_exhaustive]`. cuVS can add a
   metric or filter type, which is breaking for any exhaustive `match`; neither is a return value (they are parameters), so an unknown value cannot come back into Rust. The doc comments describe the C names but
   state no cuVS version.
4. **Public fields on 10 `#[repr(C)]` structs are the ABI.** 31 `pub` fields (`DLTensor` 7, `cuvsIvfFlatIndexParams` 8, ...), 10 `repr(C)` (grep). They mirror `dlpack.h` and the cuVS C headers, so their shape is fixed by the
   vendor, not by us; `#[non_exhaustive]` would break struct-literal construction that FFI callers need. The honest freeze statement is "matches cuVS version X", and the crate does not say which X: the README only
   says `conda install ... cuvs cuda-version=12.x`. `cuvsError_t` is a `repr(transparent)` `c_int` newtype with the inverted convention (`SUCCESS = 1`, `ERROR = 0`), documented at the top of the crate and
   on `is_success`.
5. **`cuvsFilter` carries an enum by value** (`type_: cuvsFilterType`, `lib.rs:248`) inside a `repr(C)` struct. A value outside the three variants constructed on the C side would be invalid for the Rust enum; the
   struct is only ever an input, so this is a note, not a defect found.
6. **Loader surface.** `cuvs() -> Result<&'static Cuvs, LoaderError>` resolves `libcuvs.so` / `libcuvs.so.0` (or `cuvs.dll`, `libcuvs.dll`) and each `cuvs_*` accessor `transmute_copy`s a raw symbol into the
   matching `PFN_*` (`unsafe extern "C" fn`). Adding a cuVS function adds a method and a type (additive). `Cuvs` has `Debug` only; whether it is `Send + Sync` (it holds a `Library` and `OnceLock`s) was not checked, and
   the crate has no `unsafe impl`, `doc(hidden)` or `#[non_exhaustive]` (greps over `src/`).
7. **README pin is stale.** `README.md:18` shows `baracuda-cuvs-sys = { version = "0.0.1-alpha.63", features = ["cuvs"] }` while the crate is `0.1.0-alpha.160`.
8. **Census line numbers are current.** Loop over the 42 struct/enum/fn/type/const rows: 42 checked, 0 mismatched. The lines of fields, variants and methods were not checked.
9. **One in-repo consumer.** `baracuda-cuvs` (`Cargo.toml:33`, with `cuvs = ["baracuda-cuvs-sys/cuvs"]` at `:24`); the facade does not list it. Which items it re-exports was not read.
